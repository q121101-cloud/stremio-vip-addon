## 4. Adversarial Findings & Security Notes (Non-Blocking)

- **Security Note (Script Tag Sanitization)**: In `src/handlers.js` (line 1081), `_apiKey` is injected into the client `<script>` block via `JSON.stringify(resolvedConfig.apiKey)`. While HTML attribute injection in the `<input>` element is safely escaped via `escapeHtml()`, raw `JSON.stringify` does not escape `</script>`. If a malicious actor generates a config token containing `</script>`, the browser HTML parser could prematurely terminate the script block.
  - *Mitigation recommendation for future hardening*: Replace `JSON.stringify(...)` with `JSON.stringify(...).replace(/</g, '\\u003c')`.
- **Single-Segment Route Passthrough**: In `src/config.js`, `isConfigToken()` falls back to `DEFAULT_CONFIG` on invalid tokens, causing arbitrary single-segment paths (e.g. `/unknown`) to render the default configurator page (HTTP 200) rather than HTTP 404. Multi-segment paths (e.g. `/unknown/path`) correctly return HTTP 404.
