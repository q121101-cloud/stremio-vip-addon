## 2. Logic Chain

1. **Bug Resolution Verification**: Challenger 1 identified 4 defects: (a) blind search fallback accepting unrelated titles on regex characters, (b) out-of-bounds series seasons returning S1E1, (c) null parameter destructuring in `getCatalog`, and (d) non-string slug handling in `getDetail`. These have been completely remediated via `src/lib/utils.js` (`scoreMatch` with word-boundary similarity scoring >= 0.45, `isSeasonMatch` with `1 <= season <= 1000` bounds check, `safeExtra`, `safeSlug`, and `safeKeyword`).
2. **Concurrency & Resilience**: All 7 providers utilize an isolated 5000ms axios client timeout and handle promise rejection inside `getStreams` / `getCatalog` gracefully by returning `[]`. High-volume concurrency bursts (70 simultaneous requests) complete with 100% resolution stability.
3. **Unicode & Diacritics**: Diacritics stripping and normalization in `normalizeText` (`.normalize('NFD').replace(/[\u0300-\u036f]/g, '').replace(/[đĐ]/g, 'd')`) ensure that both NFC and NFD representations of Vietnamese movie/series titles match canonical upstream titles accurately.
4. **HLS Proxy & Routing Contract**: Stream objects generated by all 7 providers conform strictly to the Stremio Stream Protocol with in-app proxying via Base64URL-encoded parameters. Real video playback downloads authentic 3.34 MB MPEG-TS binary data (`0x47` sync bytes) with HTTP 200 and HTTP 206 Range seeking.

## 3. Caveats

1. **Upstream Rate Limits (HTTP 429)**: Under extreme stress testing running hundreds of queries in under a second, public upstream APIs (`phimapi.com`, `phim.nguonc.com`, `vsmov.com`) may return HTTP 429 rate limit responses. All providers handle HTTP 429/500/timeout responses gracefully by logging warnings and safely returning empty arrays (`[]`) without crashing the addon engine.
2. **Exotic JS Primitive Edge Case**: Passing a JavaScript `Symbol` directly into the `season` or `episode` property of `getStreams({ season: Symbol('foo') })` invokes `parseInt(season, 10)` before the `try...catch` block, resulting in a `TypeError: Cannot convert a Symbol value to a string`. In real Stremio usage, route parameters from Express are always strings/numbers or null, so this never occurs in production. Wrapping `season`/`episode` parsing inside `try...catch` or using `safeString` is recommended as a minor polish for subsequent milestones (M3/M4).
